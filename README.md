# 🚀 磁盘清理专家 (Disk Cleaner Pro)

[![Python](https://img.shields.io/badge/Python-3.x-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/Platform-Windows-win.svg)](https://microsoft.com/windows)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)

**一个安全、可视化的 Windows 系统清理工具。** 支持所有磁盘分区，基于 Python 原生 WinAPI 开发，提供多标签页清理功能及安全的回收站机制。

## ✨ 核心功能 (Features)

* **💾 多磁盘支持**：支持选择任意磁盘分区进行扫描和清理
* **🛡️ 安全第一**：
    * **回收站机制**：所有删除操作默认将文件移入回收站，提供"后悔药"
    * **自动备份**：支持在清理前将文件备份到指定目录
* **🧹 智能垃圾清理**：
    * 深度扫描系统临时文件 (`Temp`)、浏览器缓存 (`Chrome`/`Edge`)
    * 专为开发者优化：支持清理 `pip`、`uv`、`npm`、`Yarn` 等开发工具缓存
    * 智能识别系统盘(C盘)和非系统盘的缓存位置
* **🐘 大文件搜索**：
    * 自定义大小阈值（如 >100MB）
    * **风险评估**：通过 红/黄/绿 三色标签自动识别系统敏感文件（如 `.sys`, `.dll`），防止误删
* **🔄 重复文件检测**：快速定位占用空间的重复文件
* **📁 空文件夹清理**：一键清理无效空目录
* **🚀 启动项管理**：查看并管理 Windows 开机启动程序
* **📦 程序卸载**：快速卸载不需要的软件
* **⚡ 零依赖**：完全基于 Python 标准库 (`tkinter`, `ctypes`) 开发，无需安装第三方库
* **🎨 浅色主题**：清新简洁的UI设计
* **📝 完整日志**：详细的操作日志记录

## 🛠️ 运行环境 (Requirements)

* Windows 10 或 Windows 11
* Python 3.8+ (如果是运行源码)
* **注意**：必须以 **管理员身份 (Administrator)** 运行，否则无法清理系统路径

## 🚀 快速开始 (Usage)

### 方式一：直接运行源码
```bash
# 1. 进入目录
cd C盘清理工具

# 2. 运行脚本 (请确保以管理员权限打开终端)
python cleaner.py
```

### 方式二：打包为 EXE (推荐)

如果你想生成一个可以在任何电脑上运行的 .exe 文件：

```bash
# 1. 安装 PyInstaller
pip install pyinstaller

# 2. 执行打包命令
pyinstaller --onefile --noconsole --uac-admin --name="磁盘清理专家" cleaner.py

# 3. 在 dist 文件夹中找到生成的 exe 文件
```

## 📝 使用说明

1. **选择磁盘**：在顶部下拉菜单中选择要清理的磁盘分区
2. **垃圾清理**：点击"扫描垃圾"按钮，系统会自动扫描该磁盘的垃圾文件
3. **选择清理**：勾选要清理的项目（默认不选中），点击"清理选中"
4. **大文件搜索**：切换到"大文件搜索"标签，设置最小文件大小和搜索路径
5. **重复文件**：切换到"重复文件"标签，检测重复文件
6. **空文件夹**：切换到"空文件夹"标签，清理无效空目录
7. **启动项管理**：管理开机启动程序
8. **程序卸载**：快速卸载软件
9. **安全删除**：所有删除操作会将文件移入回收站，误删可恢复

## ⚠️ 注意事项

- 红色高风险文件请谨慎删除，可能导致系统不稳定
- 建议清理前开启"备份"功能
- 部分系统文件需要管理员权限才能清理
